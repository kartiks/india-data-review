# PRS Legislative Research reference values

Figures copied from **PRS Legislative Research, "Union Budget 2026-27 Analysis"**
(https://prsindia.org/files/budget/budget_parliament/2026/Union_Budget_Analysis-2026-27.pdf):
Table 1 (Budget at a Glance), Table 2 (receipts), and the ministry and scheme
allocation tables. PRS rounds to whole crore.

PRS is an independent analysis of the same budget documents, so a match shows
our pipeline read the official files correctly. Notes on definitions:
- Ministry totals are summed over a ministry's departments/demands. Home Affairs
  includes the Union Territory demands, as in the Demands for Grants.
- PRS's "GST" is total GST including compensation cess.
